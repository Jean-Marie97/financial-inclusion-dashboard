# Financial Inclusion Dashboard – Liberia Case Study

## 🧭 Overview

This project provides a data-driven view of the state of **financial inclusion in Liberia** using international and national datasets. It highlights key metrics such as account ownership, mobile money adoption, financial access points, and gender disparities. The dashboard is designed to inform policymakers, development organizations, and fintech innovators on the progress and gaps in Liberia's financial ecosystem.

---

## 🎯 Problem Statement

Despite improvements in mobile money penetration, many Liberians still lack access to formal financial services. Understanding *who is excluded*, *why they are excluded*, and *how digital finance is bridging the gap* is essential for inclusive economic development and digital financial services (DFS) strategy.

## 📊 Key Metrics Tracked

- % of adults with bank/mobile money accounts  
- Mobile money usage by gender & income  
- Financial institution branches per 100k adults  
- Borrowing sources: family, banks, fintechs  
- Urban vs. rural inclusion gap
